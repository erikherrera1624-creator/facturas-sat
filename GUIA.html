Facturas SAT

Guía paso a paso · sin saber programar

1Publicar tu app (una sola vez, gratis)
  1. Crea una cuenta en github.com.
  2. Arriba a la derecha: + → New repository. Nombre: facturas-sat. Marca Public. Clic en Create repository.
  3. Clic en uploading an existing file. Arrastra todo lo que hay dentro de la carpeta FacturasSAT. Clic en Commit changes.
  4. Pestaña Actions → Publicar nueva version → Run workflow → Run workflow.
  5. Espera unos 10 minutos, hasta que aparezca una palomita verde ✅.
  6. Pestaña Releases (a la derecha, en la página principal) → descarga FacturasSAT-Setup-….exe → instálalo.
Si Windows dice “Windows protegió su PC”: haz clic en Más información → Ejecutar de todas formas.
Si en el paso 4 no aparece “Publicar nueva version”, falta la carpeta .github. Crea el archivo a mano: Add file → Create new file → nombre .github/workflows/publicar.yml → pega el contenido de ese archivo → Commit.
2Usarla gratis (modo dueño)
  1. Abre la app → Soy el dueño de la app → Crear mi llave por primera vez.
  2. Guarda el archivo .pem. Haz una copia en una USB o en la nube. No se lo des a nadie.
  3. Clic en Copiar llave pública.
  4. En GitHub abre app-config.json → lápiz ✏️ → pega la llave entre las comillas de "llavePublicaDueno": "" → Commit changes.
  5. Publica una versión nueva: Actions → Run workflow. Espera la palomita verde ✅. La app se actualiza sola en unos minutos (ciérrala y ábrela).
  6. En la app: Soy el dueño → Tengo mi llave de dueño → elige tu .pem. Listo: la usas gratis, sin anuncios.
3Cobrar cada mes
  1. Crea una cuenta en lemonsqueezy.com y registra tu cuenta bancaria o PayPal para recibir tus pagos.
  2. Products → New product → tipo Subscription, precio mensual. Activa Generate license keys. Guarda.
  3. Copia el enlace de compra del producto (botón Share).
  4. En GitHub abre remote/config.json → ✏️ → pega el enlace en "linkDeCompra" y escribe tu precio en "precioTexto" → Commit.
  5. En Lemon Squeezy: Settings → Stores → copia el número de tu Store ID. Pégalo en app-config.json → "lemonsqueezyStoreId" → Commit → Run workflow.
El cliente paga y recibe su clave por correo. La pega en la app y queda activo. Si deja de pagar, la app se bloquea sola.
¿Prefieres Gumroad? En app-config.json pon "proveedor": "gumroad" y el ID de tu producto en "gumroadProductId".
4Dar códigos de acceso
  1. En la app, en modo dueño: Panel del dueño.
  2. Escribe el nombre del cliente, la fecha en que vence y el plan (Pro sin anuncios o Básico con anuncios).
  3. Clic en Crear código. El código se copia solo; envíalo por WhatsApp o correo.
  4. Para anular un código: copia su ID y agrégalo en remote/config.json → "codigosRevocados": ["ID"] → Commit.
Úsalos para clientes que te pagan por transferencia, para regalos o para pruebas.
5Poner publicidad
  1. En GitHub abre remote/config.json → ✏️.
  2. En "lista" pon el "texto" del anuncio, el "link" al que lleva y, si quieres, la dirección de una "imagen".
  3. Commit. Todos lo ven en minutos, sin publicar una versión nueva.
Los anuncios se muestran en el plan Básico y en la prueba gratis. Para mostrarlos también a quienes pagan: "mostrarAUsuariosDePago": true.
Google AdSense no funciona en programas de escritorio. Vende el espacio directamente, por ejemplo a despachos contables, o anuncia tus propios servicios.
6Actualizar la app a todos
  1. Sube a GitHub los archivos que cambiaron (Add file → Upload files) → Commit.
  2. Actions → Run workflow.
  3. Listo. Cada usuario recibe la actualización al abrir la app y ve el aviso “Reiniciar y actualizar”.
Anuncios, avisos, precio, días de prueba y códigos anulados se cambian solo con remote/config.json y no requieren publicar una versión nueva.
¿Quieres una función nueva? Pídesela a Claude y sube los archivos que te entregue.
7Compartir la app
  1. Envía este enlace: https://github.com/TU_USUARIO/facturas-sat/releases/latest
  2. También lo encuentras en la app: Mi cuenta → Copiar enlace.
8Cómo la usa tu cliente
  1. Contribuyentes → escribe el RFC y la CIEC → elige los archivos .cer y .key → escribe la contraseña de la e.firma → Guardar.
  2. Columnas Excel → marca las columnas que quiere → Guardar.
  3. Descargar → elige Emitidas o Recibidas, el periodo y los filtros → Descargar.
  4. Los archivos quedan en Documentos\Facturas SAT\RFC.
!Importante saber
  1. Para descargar se necesita la e.firma. El SAT no permite la descarga automática solo con la CIEC. La CIEC se guarda para entrar al portal (botón “Copiar CIEC”).
  2. El SAT solo entrega XML. El PDF lo crea la app a partir del XML.
  3. El SAT tarda de 1 a 30 minutos en preparar los paquetes. Las facturas recibidas que están canceladas no se pueden descargar.
  4. La app no tiene límite de descargas. El SAT sí limita cuántas veces se puede pedir el mismo periodo; la app lo maneja sola y no vuelve a pedir lo que ya descargó.
  5. Las contraseñas y la e.firma se guardan cifradas solo en la computadora de cada usuario. Nunca se suben a internet.
  6. El aviso de Windows desaparece si compras un “certificado de firma de código”. Es opcional.
  7. El repositorio es público, así que el código se puede ver. Tu llave .pem nunca se sube.
